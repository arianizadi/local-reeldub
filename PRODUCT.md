# Using ReelDub

[Install the server or connect an iPhone](README.md#quick-start).

**From Instagram**, share a Reel to ReelDub, select its voice mode and tap **Dub video**. The extension briefly shows **Submitted** and dismisses, returning you to Instagram. Open **Dubs** to see progress or watch the result. **From a browser**, paste an individual Reel URL into your server’s home page. On iPhone, share a video from Photos or Files to use a local copy.

Every new dub uses matched speaker references. Best uses Qwen. Fast uses Kitten for English and can fall back to Qwen. Each supported output has its own audio track and switchable subtitles in the exported file. Be sure you have permission to translate the media and match the speakers.

The library shows the queue position or estimated time when available, the current stage and the completed processing time. Open a finished video to enable captions, change playback sound or export the MP4. To free device space, select finished items in Dubs and remove them from the library. The app can remove its local copies offline. It synchronizes library changes when connected. Copies exported to Photos or Files stay there.

For recovery, connection keys, cache storage and host configuration, see the [hosting guide](HOSTING.md).
